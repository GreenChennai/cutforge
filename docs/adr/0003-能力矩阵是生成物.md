# ADR-0003:能力矩阵是生成物(单一 JSON 真相源)

日期:2026-09-19(M8)· 状态:已接受 · 关联:ITERATION-PLAN-v2.0 D5/M8-5/M11-1

## 背景

V1 的 `docs/capability-matrix.md` 为手写,MCP `capability_matrix` 工具返回另一份
硬编码"必达/可选"**规划值**——两处口径互不相干,又都与实码无关:13 项"达成"
中 4 项零代码、2 项半实现、1 项实现即 Bug,却双双通过门禁(协议一致性测试只查
协议形状,不查内容真实)。**手写的达成宣称,一定漂移。**

## 决策

1. `docs/capability-matrix.json` 是唯一真相源;MCP 工具 `include_str!` 同源读取。
2. status 四值封闭:`achieved/partial/missing/optional`,只认**实码 + 对拍夹具
   证据**;`achieved` 必须带 evidence(测试/夹具名),`missing/partial` 必须带
   M11 target。无证据不得宣称达成。
3. 文档 `.md` 由 JSON 生成说明 + 人工注解(差异说明/对拍记录)构成,结论数字
   以 JSON 为准;M11 起证据列由 parity 夹具自动回填。
4. 门禁测试断言:15 项、枚举封闭、achieved 必有证据、当前诚实计数 = 7。

## 否决的替代方案

- **回填为"规划值 + 实码值"双列**:保留规划列就是保留自我欺骗的载体,V2 审查
  已证明规划列会被当成达成宣传统计。
- **由夹具运行时生成整份 JSON**:M11 才有全量夹具;M8 先立真相源与门禁,
  M11 把 evidence 从手填改为夹具回填(渐进,不阻塞止血)。

## 后果

- 矩阵-代码-夹具三方一致成为可判定门禁;"虚标"从制度上失去容身之处。
- 对外叙事从"93% 达成"回落到"47% 实码",短期难看,长期可信。
