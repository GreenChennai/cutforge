# ADR-0004:IR v3 关键帧预研——只进四属性,不做曲线编辑器

日期:2026-09-19(M10 预研决策;实现随 M11+ 按需)· 状态:已接受
关联:ITERATION-PLAN-v2.0 M10 第 5 项 / 达芬奇-剪映对标 §4.1

## 背景

剪映/达芬奇对标(计划书 §4.1)显示"关键帧动画"是与竞品的本质差距之一:
剪映支持缩放/位移/不透明度关键帧,达芬奇有全属性关键帧+曲线编辑器。
CutForge 的 IR v2 中 clip 无 keyframes 概念;渲染端亦无插值消费。

## 决策

1. **IR v3(schemaVersion "3.0.0")增加可选 `clip.keyframes`**:
   `[{ "at": <0..durationMs>, "attr": "position"|"scale"|"opacity"|"volume",
       "value": <number|[x,y]>, "ease": "linear"(默认)|"hold" }]`
   ——只做 **position / scale / opacity / volume** 四属性;时间基准是 clip 相对域。
2. **不做曲线编辑器**(Cubic Bezier 手柄 UI):V2 的差异化在"AI 原生可审计",
   不在专业深度(D3);`ease` 枚举封闭,linear/hold 已覆盖 AI 生成动画的
   常见语义,复杂缓动留待真实需求出现再立项。
3. **渲染消费顺序**:opacity/scale → ffmpeg `fade`/`scale` 表达式;position →
   `overlay` x/y 表达式;volume → `volume` 表达式;逐关键帧 `between(t,..)` 组合。
4. **兼容策略**:v2 工程无 keyframes 字段 → 迁移器仅升 schemaVersion,零改写;
   v3 渲染器对无 keyframes 的 clip 走现有静态路径(缓存键不含新字段时不变)。

## 否决的替代方案

- **全属性关键帧**(rotation/mask 等):渲染端消费面爆炸,V2 无真实素材牵引;
- **第三方动画 DSL**(如 lottie):违背最小依赖纪律(ADR-0034 谱系);
- **不进 IR、只在编辑器内存态**:违背"文件真相源"纪律——不可审计的动画等于不存在。

## 后果

- v3 契约面小(一个可选数组 + 两个枚举),双端校验器增量小;
- M11 渲染矩阵不包含关键帧消费(矩阵已锁 15 项),关键帧消费作为 M12 候选项;
- AI 生成动画获得可审计载体:每帧变化都是 Op,可在差异面板回放。
