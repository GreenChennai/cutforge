# ADR-0005:M12"专业分轨"整体暂缓——V2.0 不含调色/OTIO/曲线变速

日期:2026-09-19(M12 决策点)· 状态:已接受(全权委托口径)
关联:ITERATION-PLAN-v2.0 §6 M12(按需启动,各子项独立立项)

## 背景

M12 为计划书中的可选方向,子项各自独立:①调色基础(Lift/Gamma/Gain + LUT 进 IR v3);
②Fairlight 式音频表(电平/响度计);③OpenTimelineIO 导入导出;④剪映向曲线变速 UI、
蒙版、音频分离(afftdn 降噪)。计划书明确"各子项独立立项,不设统一门禁,启动前须 ADR"。

## 决策

**V2.0(本次发布)不启动 M12 任何子项**。理由:

1. **V2 的核心矛盾已解决**:V2 审查判定"运行时主链路断裂(结合度 8/20)";
   M8-M11 修完 5 P0 + 主链路 + 编辑能力 + 矩阵必达 13/13 实码——
   "AI 原生编辑器"的差异化主张已经成立,专业深度不是当前瓶颈。
2. **无真实素材牵引**:调色/降噪/OTIO 均需要真实工程需求验证参数口径
   (M11-R2 同因);合成媒体立项 = 重蹈 V1 虚标覆辙。
3. **依赖纪律**:OTIO 引入违背最小依赖(需独立 ADR 论证 + 绑定版本),
   无消费方时不引入。

## 触发重启的条件(任一满足即单独立项)

- 出现真实工程需求:用户素材需要调色/降噪,或需要与达芬奇/OTIO 生态交换;
- 必达矩阵出现回归,证明现有域需要更深的音频/色彩语义;
- parity 夹具基建可复用且新增子项能同步建立专属夹具(门禁先行纪律)。

## 后果

- V2.0 发布范围收敛为 M8-M11 + M13;矩阵整体 13/15(87%),如实陈述;
- M11 的 parity 夹具基建、ADR-0004 的 keyframes 预研,均作为 M12 子项的
  启动资产保留。
