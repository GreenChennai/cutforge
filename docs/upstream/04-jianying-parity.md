## 2. 本轮实施范围(壳,均已实测)

- H1/H2/H3:顶栏三段(品牌+工具组 | 居中工程名 | 保存状态+导出按钮);
- P1:时间码 HH:MM:SS:FF(工程 fps);
- T1:时间线工具行(撤销/重做/分割/删除/冻结帧 + 缩放滑杆 + 适应);
- T2:轨道头 锁/M 两键接 track_update(隐藏键视觉位预留);
- T3/T4:视频/图片片段缩略图条(media_thumbnail 串行抽帧按 src 缓存,
  sable TimelineView `set_clip_thumbs` 平铺渲染);
- L1/L2:媒体卡「已添加」徽标 + 搜索框;
- S1:开始界面(Home):新建工程卡(默认工程根下按名称创建,project_new)+
  最近工程网格(recent.json)+ 打开已有目录;选择后原窗口切换编辑器视图,
  内核子进程随视图启动/随壳退出。

## 3. 内核缺口(壳不做语义,逐条候内核)

1. **缩略图批量工具**:media_thumbnail 单 src 串行 N 次拉太慢;候
   `media_thumbs {src, atMs[], width}` 批量 + 磁盘缓存复用;
2. **导出预设参数面**:render 工具已有 format/preset/qualityTier,壳侧
   导出对话框候 P1(参数面/进度 render_progress/取消);
3. **关键帧**:ui-fields readonly 已列 keyframes,编辑语义+插值候内核;
4. **轨道显示切换(隐藏)渲染语义**:track_update.hidden 已支持(工程模型
   有字段),但预览 render_frame 是否尊重 hidden 候验证;
5. **多选/框选/Shift 选择**:内核命令面单 clip 粒度,多选批操作候内核;
6. **右键上下文菜单**:gpui-component PopupMenu 接线(纯壳,候后);
7. **自动保存/崩溃恢复**:内核 oplog 已有,壳态(recent/窗口布局)候壳;
8. **代理预览开关**:render_frame use_proxy 参数已存在,壳入口候后。

## 4. 诚实验收口径

- 每条 P0/P1 落地必须:真实点击回归 + 截图留档 + 门禁全绿;
- 视觉对齐剪映的**布局信息架构**,不逐像素复刻(字体/图标系统不同);
- 凡「声称已支持」必须有对应交互实测;否则写入本文件待办,不粉饰。
