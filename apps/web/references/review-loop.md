# 交付后审阅闭环(Review Loop)

> 来源:MV 审片台资产包 20261007(真实 MV 工程 33 轮返修沉淀,32 条铁律;
> 原包 Apache-2.0/MIT 学习性移植,出处 `MV审片台资产包-20261007/02_经验·铁律/`)。
> 落到 cutforge 的形态:**标注面板 = 审片意见的 Agent 接口**(全部走既有
> notes_add/notes_list/note_reply 契约,零新真相源);本分册沉淀交互铁律与
> 审阅工作流,供人与 Agent 共同遵守。

## 一、核心铁律(编号沿用源包,便于溯源)

### 铁律⑨:审片意见必须落盘成文件——这是给 Agent 用的接口

意见不是聊天记录,是**下一轮迭代的输入**。cutforge 的落盘通道 = `notes_add`
(锚点五类:clip/track/time/word/subtitleCard;author=user/agent;tags 自由
口径),内核落盘、OpLog 审计、结案回执闭环。**禁止**把意见留在对话里让人肉
转述——转述即失真,失真即返修。

### 铁律⑩:字幕/画面是"源自己的图层"——审片层只叠加,不改源

审片台的高亮/tooltip/意见徽标全部是**壳侧叠加层**;对 cutforge:拾取器的
overlay、意见锚定徽标不得改工程数据(零 RPC),意见里携带的 DOM selector 是
**壳事实**(会随壳重构漂移),只作定位参考,**永不**写进工程真相(tags 里带
`dom:` 前缀显式声明其易变性)。

### 铁律⑬:保存层必须抗打(离线队列 + 自动重连补写)

保存失败 ≠ 丢失:写不进就排队,服务恢复自动补写。cutforge web 壳的命令通道
(enqueue)已含此语义;审片意见走同一通道,不开旁路。

### 铁律⑮:行内编辑三条硬规则(contenteditable/input 类通用)

1. **合成输入事件是唯一可靠注入**(RDP/无头环境验证口径);
2. Enter 拆句 / 行首 Backspace 并句必须**互为逆操作**(铁律⑯同源);
3. `\s` 清洗会吃掉刚生成的换行——清洗顺序先保行结构再做字符级清理(铁律㉒)。

### 铁律⑧:缓存只能影响预览——三道防线

缓存命中加速审阅,但**真相永远在内核**(rev + OpLog)。任何"缓存态"与
"服务端态"分歧时,以服务端为准并全量对账;缓存审计与指纹口径见内核
`fresh.rs`(oplog 首/末行 rev + 末行 FNV)与渲染缓存(RENDERER_VERSION 位)。

## 二、审阅工作流(人与 Agent 的分工)

1. **人**:拖时间线逐帧看(或 `锚定此帧` 钉住某个画面)→ `拾取元素`
   (Ctrl+Shift+C)点出"就是这里" → 写一句"要怎么改" → 创建。
   意见自动携带:atMs(帧锚)/ DOM selector(壳内定位)/ tags=审片。
2. **Agent**(下一轮):`notes_list` 读 open 态意见 → 按 anchor.tMs 定位画面
   → 改工程(命令通道)→ `notes_resolve` 带 opIds 结案(回执闭环,审计链
   把意见与改动绑在一起)。
3. **循环**:每轮返修的意见/结案都在 OpLog 里;`session_report` 生成人话
   Markdown(改动段/操作分布/回执率)。

## 三、机检与验收口径(移植自源包 03_脚本/机检门禁 的方法论)

- **意见可机检面**:每条 open 意见必有非空 body + 合法 anchor(tMs ≥ 0);
  结案必有 reply(允许空 opIds,但必须显式"无需改动"类回执)——缺一即
  流程违规,e2e 可断言。
- **锚定帧可复现**:`锚定此帧` 创建的意见,其 tMs 与创建时播放头差 ≤ 1 帧
  (帧网格量化口径;回放 seek(tMs) 后截图应与意见语境一致)。
- **拾取器不污染**:检查模式退出后零事件残留(mousemove/click/keydown
  listener 全部摘除);overlay/tip 隐藏;body class 复位——e2e 断言。
- **缩略图会骗人,必须量化**(源包诊断方法论):"看起来对了"不算过,像素
  基线 diff 或 numpy 量化通过才算——cutforge 侧对应 `verify_px` 类门禁
  (与 compare.py 的重叠裁决见资产包 §五)。

## 四、与 cutforge 既有面的关系(零双真相源声明)

| 审片台概念 | cutforge 承接 | 说明 |
|---|---|---|
| 意见文件(JSON) | notes_add → 内核 notes 真相源 + OpLog | 同一真相,无第二落盘 |
| 字幕轨审阅 | subtitle_set/subtitle_import + 字幕页签 | 壳只投影 |
| 元素拾取 | 壳 DOM selector(tags `dom:` 前缀) | 壳事实,非工程真相 |
| 性能面板 | view.perf(既有) | 同一实现 |
| 逐帧对照成片 | compare.js(既有) | 源包"成片对照"能力的壳内等价 |
