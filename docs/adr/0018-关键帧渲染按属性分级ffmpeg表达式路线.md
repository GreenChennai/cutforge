# ADR-0018:关键帧渲染路线——按属性分级走 ffmpeg 表达式(逐属性映射表),否决抽帧插值与纯线性

日期:2026-09-30 · 状态:已采纳(册五 D-E1,动工前落库)
关联:册五迭代计划 T5.1/D-E1/AC-5.1 · ADR-0004(v3 关键帧预研,本 ADR 扩为正式渲染路线)· A4 交接清单 #1(speed_segments 单一真相源)· A4-L1(fx.in/out 槽位登记不渲染)· E-R2(专业功能与个人自用取舍)· 计划书 §5.C(达芬奇/剪映关键帧对齐)

## 背景

T5.1 关键帧引擎把可动画属性白名单定为 position.x/y、scale、rotation、opacity、volume、fx 参数、speed,插值面含线性/缓动/贝塞尔四参数。渲染端两条候选路线:(a) **ffmpeg 表达式**——把关键帧曲线编译为滤镜表达式,每帧在 ffmpeg 内求值;(b) **抽帧插值**——按帧离散求值,逐帧产出独立静态画面。D-E1 要求"按属性分级,须 ADR;抽帧插值需评估性能"。ADR-0004 只做了纸面方向(opacity/scale→fade/scale、position→overlay、volume→volume 表达式,四属性、仅 linear/hold),本 ADR 把它扩成覆盖贝塞尔、有本机实测依据、含否决项与降级路径的正式决策。候选滤镜的本机实测基线:ffmpeg 2026-07-30 full build,`overlay` x/y(表达式 + eval=frame,`..FV.....T.`)、`rotate` angle(表达式,`.....T.`)、`volume`(表达式 + eval=frame)、`geq`(TS,表达式含 T 变量)、`zoompan`(z/x/y 逐帧表达式)——四条表达式通路均以 0.5s 实渲通过(smoke:t/on/T 变量各一);`scale` 的 w/h 表达式变量面(libswscale 域)**不含 t**,不能做每帧连续缩放,同批实测排除。

## 决策

**按属性分级:表达式路线为主轴,每个白名单属性一张映射表;不达表达式的属性走明确降级路径,绝不退回全量抽帧。**

1. **分级映射表**(求值单源纪律见决策 3;映射为路线选定,逐属性滤镜参数在实现期以实渲对拍钉死):

| 属性 | 级别 | 渲染映射 | 依据 |
|---|---|---|---|
| position.x/y | A 表达式直译 | 合成层 `overlay` x/y 表达式(eval=frame,t 变量;与既有 overlay 步同域,不另起合成通道);关键帧区间编译为嵌套 `between(t,…)`+lerp 分支 | 本机实测表达式通路通过 |
| rotation | A 表达式直译 | `rotate` 角度表达式(弧度,t 变量),接在既有变换链 crop→flip→rotate 的 rotate 位 | 本机实测通过;链序沿用 BE2 变换链 |
| scale | A(特殊宿主) | `zoompan` z/x/y 逐帧表达式(on 帧计数,Rust 编译器按 fps 把 ms 换算为帧索引;输出尺寸锁画布域);`scale` 滤镜因表达式无 t 变量不承担此职 | zoompan 实测通过;scale 变量面实测排除 |
| opacity | A(表达式+特例优化) | `geq` alpha 平面表达式(T 变量,rgba/yuva 域);纯线性淡入淡出特例**可**编译为 `fade`(性能优化,语义等价由对拍保证,不改变路线归属) | geq TS + T 变量实测通过 |
| volume | A 表达式直译 | `volume` 表达式(eval=frame,t 变量),接既有音频链 | 本机实测通过 |
| speed | B 分段子段 | **不引新机制**:speed 关键帧展开为 `speed_segments` 分段(分段常速逼近曲线),走既有分段积分变速路径;时长语义三道对拍(A4 交接 #1)免费继承,零新增对拍面 | speed_segments 单一真相源已建(BE2) |
| fx 参数 | B 逐项评估 | fx 注册表逐项标注时间轴能力三态(见决策 4);支持 timeline 命令的滤镜走 `sendcmd` 命令序列,否则分段子段重建滤镜串;A4-L1 fx.in/out 槽位随本路径补真实渲染 | 本机 `-filters` T 标记枚举(eq/volume/colorchannelmixer 等);逐项登记随 T5.1 落地 |

2. **编译规则**:关键帧区间 [kf_i, kf_{i+1}) 编译为一个表达式分支(嵌套 `between(t,..)`+lerp);贝塞尔(ease 四参数)编译为 t 域闭式有理表达式树;超出表达式表达能力的缓动(回弹等)降级为**分段线性逼近**(采样密度实现期定,逐样本对拍阈值把关)。编译器是确定性纯函数,产物(表达式串/分段表)进单测对拍——与 ADR-0016"片段→临时 ASS 确定性生成"同型纪律。

3. **求值器单源纪律(Rust 求值,壳零插值)**:同一份(关键帧, 插值, 区间)输入只有一个求值实现——Rust 求值器。(a) 预览面:Rust 求值后以采样序列进投影下发,壳只画投影样本,不插值、不内置表达式引擎(T5.1 单源纪律明文);曲线编辑器画布的曲线形状同样吃投影采样点集,不得按公式自行重算。(b) 渲染面:Rust 编译器产出 ffmpeg 表达式/分段表。因此 ffmpeg 表达式引擎是**编译目标**而非第二求值真相:一致性由**逐样本对拍**兜住(AC-5.1)——渲染产物在固定采样点实测(位置/角度/尺寸/alpha/响度),与 Rust 求值器同点输出比对,阈值内视为一致;夹具进 parity 矩阵。

4. **fx 参数时间轴能力三态**:注册表每参数标注 `sendcmd`(T 标记滤镜,命令序列直达)/`segment`(分段子段重建滤镜串,分段边界=关键帧)/`static`(不可动画,工具面打点诚实禁用——与"缺通道诚实禁用"同口径)。三态标注是 fx 注册表 schema 的一部分,未标注即视为 static。

## 取舍

- 表达式路线的本质优势:**渲染管线结构不变**(probe→segment→compose→overlay→mix→subtitle→encode),关键帧只是把滤镜串参数域从常量扩为表达式;缓存层、对拍、降级语义全部沿用。抽帧插值则每帧重建滤镜链,产物无法按段缓存——预览交互(拖贝塞尔手柄)每帧全量重渲,千素材 P95 63.3fps 基线与 AC-5.7 零劣化双双不可达。
- 代价:表达式串是"另一种源代码",其正确性不能靠肉眼——编译器单测对拍产物 + 逐样本实渲对拍双闸;求值精度差异(ffmpeg 表达式引擎 vs Rust)以对拍阈值收敛,不靠口头信任。
- geq 是唯一逐像素通路,只挂在**有 opacity 关键帧的片段**(按需挂载);无 keyframes 字段的 clip 渲染路径与缓存键零变化(ADR-0004 兼容口径延续,v2 迁移零改写)。

## 被否决的替代

- **全量抽帧插值**(逐帧独立渲染):否决——性能不可接受(逐帧滤镜链重建 + 缓存粒度碎片化,AC-5.7 直接破线);在个别属性上保留的"分段子段"(B 级)是分段常量近似,不是逐帧抽帧,两者不同物。
- **只支持线性插值**:否决——达芬奇心智不合格(AC-5.1 明文贝塞尔插值,剪映亦有缓动预设);线性-only 是伪关键帧,T5.1 曲线编辑器(贝塞尔手柄)无从谈起。回弹等不可闭式编译的缓动降级为分段线性**逼近**,是求值精度折衷,不是砍掉缓动。
- **壳侧插值**(壳自持求值器):否决——双求值源必漂移,直接违反 T5.1"Rust 求值 → 投影序列化,壳不自行插值"明文;无构建 ESM(ADR-0011)上也养不起第二个数值内核。
- **speed 走 setpts 表达式**(表达式域做非线性变速):否决——speed 关键帧的时长语义(变速改时长、时长改下游布局)与 speed_segments 积分口径构成双真相源;分段展开复用既有积分路径,时长对拍零新增(决策表 B 级)。

## 后果

- 渲染链新增"关键帧→表达式/分段表"确定性编译器(纯函数 + 单测对拍产物);无 keyframes 的 clip 渲染路径/缓存键零变化。
- fx 注册表增时间轴能力三态标注列;不可动画参数的打点在工具面诚实禁用;A4-L1(fx.in/out)随本路径核销。
- 白名单外属性(如 crop、textStyle 内字段)本期不打点;需求出现按本 ADR 分级框架逐属性增补映射表,不破坏求值单源。
- bench 增"有关键帧 vs 无关键帧"渲染耗时对照(AC-5.7 证据位);schemaVersion 升 3.0.0 的契约面(schema/迁移器/双端校验)随 T5.1 走 CONTRACT-WORKFLOW 七步。
