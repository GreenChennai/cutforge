# ADR-0011:壳构建策略选无构建 ESM 多文件,不引入 Vite + TypeScript

日期:2026-09-29 · 状态:已采纳(册二 D-B1,动工前落库)
关联:册二迭代计划 T2.1/AC-2.1/AC-2.6 · 风险表 B-R2 · ADR-0009(HTTP 层纯 std,同一最小依赖纪律) · check-shell-purity 门禁

## 背景

册二要把 `apps/web` 从 3 文件原型重写为模块化工程(js/core、js/render、js/panels、js/ui,单文件 ≤400 行)。动工前决策点 D-B1:前端工程化走方案 A **无构建 ESM**(原生 ES Modules 多文件 + 册一 `/assets` 目录托管),还是方案 B 引入 Vite + TypeScript 工具链?

现状事实:册一 T1.6 已交付 `/assets/*` 目录化静态托管(新增文件零 Rust 改动、零重启可达,ETag/304 齐备),ESM 拆分的托管前提已经成立;`check-shell-purity` 门禁按"壳目录内 js/html 逐行扫描"建模,假设磁盘文件即交付物;全仓纪律是零 npm 依赖、单二进制分发(E1-2)。

## 决策

1. **无构建 ESM**:源码即交付物——原生 ES Modules 多文件,浏览器直接加载,零 npm 依赖、零打包器、零 node 工具链步骤。
2. **TypeScript 能力以 JSDoc + `checkJs` 获得**:关键数据形状(投影行/envelope/store patch)用 JSDoc `@typedef` 注释声明,`jsconfig.json` + `checkJs` 可在编辑器/CI 侧获得类型检查而不改变交付物形态。
3. 部署契约不变:仍由 cutforge-mcp serve 直接托管 `apps/web/` 目录;`index.html` 经绝对路径 `/assets/…` 引用全部子资源(根路径 `/` 只保留 index.html 与历史别名)。

## 取舍

- 代价一:**无类型严格度**——没有编译期类型墙,字段拼写错误只能靠 `checkJs` + e2e 兜底。以 JSDoc 全量标注投影行/envelope 形状 + 「断言以服务端状态为准」的 e2e 纪律补偿。
- 代价二:**无代码分割/压缩**——本地 127.0.0.1 单用户场景,几十个未压缩小文件的加载开销可忽略;真按需拆分由 ESM import 图天然给出。
- 代价三:**无热更新**——ETag 协商缓存 + 手动刷新足够;本地迭代体验损失有限。
- 收益:与 C4 最小依赖纪律、壳纯度门禁(禁压缩包/禁 fs/禁 node 能力面)、单二进制分发完全兼容;部署零工具链,`cargo build` 之后没有任何一步;审计面 = 磁盘上可见的源码本身。

## 被否决的替代

- **Vite + TypeScript**:否决——①引入 node_modules 与构建产物目录,把「磁盘文件即交付物」变成「构建产物即交付物」,check-shell-purity 必须同步修订且审计面从源码退化为产物;②违背单二进制分发(发布包要多带一份构建流程或预构建产物);③为单用户本地编辑器引入整条 npm 工具链是数量级错配,与 ADR-0009 拒绝 HTTP 框架同一逻辑;④册三至册七的全部 UI 需求都没有超过无构建 ESM 能力面的证据。
- **单文件 IIFE/全量拼接**:否决——正是本册要消灭的巨石形态(计划书 §0.4 W1)。

## 后果

- 壳内模块边界只能靠目录纪律与 import 图约束,没有编译器强制;以「每文件单一职责 + ≤400 行」门禁补偿(AC-2.1)。
- 若未来出现真实需求(如册七 Editor API 的第三方插件签名分发),再开新 ADR 论证引入面;届时本决策的适用边界以「个人自用、本地 127.0.0.1」为准(与 ADR-0010 定位一致)。
- `jsconfig.json` 仅服务编辑器/`checkJs`,不进任何构建流程。

## 落地证据

- `apps/web/index.html`:`<script type="module" src="/assets/js/main.js">`,子资源全部 `/assets/` 绝对路径。
- `apps/web/js/`:core/render/panels/ui 四层 ESM 模块;`apps/web/jsconfig.json`(checkJs + JSDoc 形状标注)。
- `apps/web/legacy/`:旧三文件原样保留(B-R1 回退期设施,经 `/assets/legacy/index.html` 访问)。
