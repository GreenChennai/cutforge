# ADR-0016:文本渲染主路线选 ASS 生成(复用烧录链),drawtext 仅记录为性能兜底不实现

日期:2026-09-29 · 状态:已采纳(册四 D-D2,动工前落库)
关联:册四迭代计划 T4.7/D-D2/AC-4.4 · FLOW.md §5.6(sub 渲染缓存层)· 计划书 §4.C(旧版 rs_subtitle 字幕引擎算法吸收)· E-R1(资源型依赖不受限)· ADR-0009(最小依赖纪律同域参照)

## 背景

册四最大缺口:契约有 `text` 字段但渲染端不产出文本层(现在文本轨片段仅是锚点)。T4.7 要求文本渲染落地 + 样式面板(字体/字号/颜色/描边/底衬/阴影/对齐/行距/透明度)+ 花字模板 + 卡拉OK高亮。两条候选路线:(a)文本片段在渲染时生成临时 ASS,复用既有字幕烧录链(libass);(b)ffmpeg drawtext 滤镜逐片段直画。另有(c)HTML/浏览器渲染截帧的野路子需要显式排除。

## 决策

**ASS 生成为主路线,且是唯一实现路线**:

1. **生成路径**:文本片段(内容/样式/位置/入场出场动画)→ 内核侧**确定性**生成临时 ASS(Style 段 + Dialogue 行,`\fad`/`\move`/`\t` 等标签承载动画)→ 交给与字幕烧录完全相同的通道(subtitles 滤镜 + `sub/` 渲染缓存层)。文本轨与字幕轨在渲染端合流:字幕 = 特定来源的文本,渲染不分叉。临时 ASS 走会话 tmp,不进工程目录、不进 OpLog;生成函数纯函数化,单测直接对拍生成产物。
2. **字体资源策略**:**系统字体枚举 + 片段 `fontfamily` 字段**,不捆绑字体文件。字体属资源型依赖,本就不受 E-R1「最小代码依赖」纪律限制(不捆绑不是纪律所迫,是仓库体积与授权清晰度的自主选择);渲染时经 libass/fontconfig 探测系统字体,样式面板从枚举结果选。字体缺失时降级默认字体 + WARN(与 fxId 未注册降级同型语义)。
3. **卡拉OK**:`\k`/`\kf` 标签由 ASS 原生承载,卡拉OK高亮直接吸收旧版 rs_subtitle 的 k 标签生成逻辑(计划书 §4.C 明文的算法吸收项),渲染端零新增通道。
4. **drawtext 仅记录为性能兜底,不实现**:触发条件 = bench 出现实测证据——"静态短文本、大规模并发渲染场景下 libass 烧录成为可测量瓶颈"(数字留档 `docs/bench/`),届时按逐案 ADR 重开。触发条件未满足前,**不写任何 drawtext 代码**,避免双路线并存的维护与一致性负担。

## 取舍

- ASS 路线的本质是**用一份文本格式买下全部样式能力**:描边/底衬/阴影/行距/对齐/逐字卡拉OK/花字富文本全是 libass 原生特性,T4.7 的四个子需求(渲染/样式面板/花字/卡拉OK)在一条通道上全解;烧录链、缓存层、降级语义全部复用既有实码,增量最小。
- 代价:文本渲染质量上限 = libass 能力(个人自用场景下这不是损失);新增"片段→ASS"生成层,是一段必须确定性、可单测的纯逻辑——换来的是 e2e 像素断言的稳定性(同输入同产物)。
- drawtext 看似"少一层生成",但每个样式参数都是滤镜串转义地狱,逐字卡拉OK与花字根本无解,省下的生成层会以十倍的滤镜串复杂度还回来。

## 被否决的替代

- **drawtext 主路线**:否决——样式贫乏(无逐字卡拉OK、无花字富文本、底衬/描边/行距控制粗糙),与 T4.7 样式面板三件套直接冲突;但保留为纸面兜底路线(触发条件见决策 4),不是永久排除。
- **HTML/浏览器渲染截帧**(壳里画文本、无头浏览器截帧合成):否决——引入浏览器/无头渲染依赖,破坏纯净机与最小依赖纪律(ADR-0009 同域);字体度量跨机漂移使截帧不确定,AC-4.4 的像素断言失稳;渲染确定性纪律(同工程同产物)无从保证。

## 后果

- 渲染管线新增"文本片段→临时 ASS"确定性生成步骤:单测对拍产物、临时件生命周期与会话绑定、不入盘不入撤销(与 ADR-0013 精神一致:渲染侧派生物不持真相)。
- 字体是运行时环境属性而非工程资产:换机打开工程,字体枚举不同会导致渲染差异——降级 + WARN 是契约行为,不在"缺陷"口径内;工程文件只存 fontfamily 名,不存字体。
- 双路线禁令生效:渲染代码中出现 drawtext 即视为违反本 ADR(code review / 门禁可 grep 判定)。

## 落地证据(动工后核销)

- 渲染链文本层(片段→临时 ASS 生成函数 + 单测产物对拍)、`sub/` 缓存层复用记录。
- 字体枚举探测与 fontfamily 字段 schema、降级 WARN 路径。
- `docs/bench/` 预留 drawtext 兜底触发条件的实测留档位(无证据则留空并注明)。
