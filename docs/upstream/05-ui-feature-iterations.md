### 0.4 工程质量账(鲁棒性与耦合,不粉饰)

1. **重拉式对账**:任何变更 → 事件长轮询 → 后台整帧重拉 5 个请求(project_get/timeline_get/ui-fields/catalogs/media_browse,`app.rs:222-327`)→ Snapshot 全量 clone,一帧内多面板各 clone 一次(`state.rs:119-121`)。1k clips 工程会卡。
2. **上帝实体**:所有面板持 `WeakEntity<DesktopApp>` 直读直写;`TimelineHost::render` 渲染期 mutate 另一实体(`timeline.rs:481-485`);播放头/选择/剪贴板/吸附/状态全堆在 DesktopApp(`app.rs:35-62`)。
3. **桌面壳零测试**:`apps/desktop/src` 无一处 `#[cfg(test)]`;快捷键-命令拼装(close_gap 轨道反查 `app.rs:648-668`、paste 源轨反查 `app.rs:622-645`)全靠手测;桌面壳零 e2e(web 壳有 20 份)。
4. **单文件超红线**:`inspector.rs` 975 行;`timeline.rs` 790、`app.rs` 786 逼近。内核侧 `cutforge-mcp/src/dispatch.rs` 1130 行单 match 分派。
5. **错误呈现弱**:一切失败收拢为状态栏单行截断文本(`app.rs:274-287`);错误码命名空间 `ns` 字段壳未消费(`rpc.rs:147-158`);长轮询错误静默吞(`app.rs:199-202`)。
6. **契约软点**:`render_frame` 响应任意层级扫 `.png` 字符串(`preview.rs:521-528`);缩略图 `file`/`media` 双键兼容(`timeline.rs:304-308`);project_get 平铺形状宽容(`app.rs:229-233`)。
7. **撤销栈无上限**:`engine/mod.rs:39-40` `Vec<String>` 无 truncate——内存上只是 id(便宜),真实风险在 OpLog 无限增长与 `rebuild_stacks` 全量重放耗时,快照机制却**缺省关闭**(`cutforge-io/src/snapshot.rs`,env `CUTFORGE_SNAPSHOT_INTERVAL_MS` 才开)。
8. **内核子进程 stdout/stderr 全丢弃**(`kernel.rs:51-52`):壳对内核崩溃/卡死无感知,无看门狗。
9. **缩略图串行 N 次单发**:04 文档自认太慢,批量工具是内核缺口 #1。
10. **播放头请求点钳 duration-100ms**(`app.rs:337-341`,避免抽帧落空):治标,根因在渲染管线的帧寻址边界。

## 1. 设计铁律(继承 + 新增)

1. **语义在内核**:壳零语义纪律不破;凡新交互需要新语义,先立内核命令/契约,壳不私自推导(04 文档铁律延续)。
2. **动效只为状态变化服务,拖拽全程零动画**(web 壳 60 项微交互的既有纪律,搬进 gpui):时长梯度 **80ms(按压/悬停)/ 160ms(面板/浮层)/ 240ms(视图切换)**;入场 ease-out-quart、位移 ease-in-out、吸附脉冲 spring;设置页 **reduced-motion 一处总控**。gpui 侧新增 `fx` 模块统一 token 与 helper,禁止散写 ms。
3. **诚实呈现**:内核没有的能力,壳显示"待内核支持"区(既有做法),不伪造可用态;每轮"声称已支持"必须有真实点击回归 + 截图 + 门禁全绿。
4. **性能预算是门禁不是愿望**:沿用 web 壳 perf-budget 口径换算到桌面壳——交互投影收敛 ≤16ms、时间线 1k clips 滚动 ≥55fps、首帧 <1s、任何提交反馈 <100ms 内出现视觉确认(乐观预览)。
5. **不阻塞 UI**:解码、抽帧、渲染、导出一律后台线程/进程;UI 泵只消费结果。内核子进程崩溃时壳停机但不僵死(见 I1/I9)。

## 3. 迭代详解

> 每轮固定栏目:目标 / 改动清单(内核·契约·壳)/ 交互与动效规格 / 鲁棒性要求 / 验收门禁 / 不做清单。
> 工单落 `docs/tickets/`(按轮前缀 I1-、I2-…),门禁按 AGENT-ENVIRONMENT §2 真实运行。

### I1 播放引擎——让时间线"活"起来 【硬骨头 B1】

**目标**:从幻灯片(0.17s/帧)升级到流畅预览 + 声音。这是全计划最大的骨头,第一个啃。

**分三个内部里程碑(同一轮内交付,不做完不关门)**:

- **M1 单 clip 直解码**:播放头所在 clip 的原素材经 `ffmpeg -ss <in> -i <src> -f rawvideo -pix_fmt rgba -` 管道解码(后台线程环形缓冲 24 帧),gpui 每帧纹理上传;音频 `-f f32le -ar 48000 -ac 2 -` → cpal 输出,**音频回调为主时钟**驱动视频步进。片段切换(播放头跨 clip)无缝续播下一个片段流;转场区间以交叉淡化近似。
- **M2 时间线 zone 预览渲染**(Kdenlive Timeline Preview 模式):后台调渲染管线以 1/2 分辨率 + CRF 加粗渲染 [t-2s, t+8s] zone 到 `.cutforge/preview-cache/`(复用 render 的内容寻址缓存与 RENDERER_VERSION 失效语义);播放优先走 zone 文件,zone 未命中回落 M1 直解码。工程任何提交 → 当前 zone 脏标记 → 空闲重渲。
- **M3 播放 UI 完整化**:JKL(帧步/播放/快放)、倍速 0.25~4x、循环区间播放、静音键;预览面板小按钮组(04 差距表 P2:**画质切换/截图/全屏**在此一并落地——截图=render_frame 落 PNG 到工程目录,**代理开关**=缺口⑧的 use_proxy 入口)。

**改动清单**:壳新增 `playback/` 模块(decoder.rs / audio.rs / clock.rs / zone.rs),`app.rs` 幻灯片泵退役为降级路径;内核仅新增 zone 渲染编排工具 `preview_zone_render {startMs, endMs}`(参数面在 render 工具已具备,编排为薄封装)。内核缺口④(track hidden 在 render_frame 的尊重性)在本轮实测并落文档。

**交互与动效规格**:
- 播放/暂停按钮 80ms 按压态;播放头在播放时平滑步进(逐帧重投影,不做插值动画——帧即真相);
- 空格按下 → 播放键图标 80ms 切换 + 时间码立即变色(状态确认 <100ms 铁律);
- 预览区尺寸变化(代理档切换)160ms ease-in-out;
- 拖进度条**零动画**(直接映射);松手才恢复播放。
- 首次进入 M2 zone 渲染时,预览右下角出现"预览渲染中 n%"角标(数据来自 render_progress),完成即 160ms 淡出。

**鲁棒性要求**:解码线程 panic 不带崩壳(线程边界 catch);ffmpeg 进程僵死 3s 无输出 → 杀进程回落幻灯片模式并在状态栏给出可展开原因;音频设备打开失败 → 静音继续播视频;**内核子进程退出 → 播放立即停机 + 顶栏断连横幅**(看门狗完整版在 I9,先立横幅)。

**验收门禁**:cargo fmt/clippy/test/build 全绿;1080p H.264 工程预览 ≥24fps 连续 60s(日志留档);音画漂移 <1 帧(打点视频实测);解码失败注入测试 → 回落幻灯片;截屏留档。

**不做**:不做全时间线实时合成播放(等价于边导出边播,预算失控,OpenShot 前车之鉴);不做调色/特效实时 GPU 预览;预览画质明确标注"预览画质,精确画面以导出为准"。

### I2 增量同步与性能底盘 【硬骨头 B2】

**目标**:杀死"每事件 5 请求全量重拉 + 每帧多份 Snapshot 克隆",为 I3 起的一切批量交互铺路。

**改动清单**:
- 内核:`timeline_get`、`project_get` 增可选 `sinceRev`;有 sinceRev 且日志连续 → 返回 `{rev, ops: tail(sinceRev)}`(直接复用 `oplog.rs` `tail` 按 rev+actor 过滤,零新语义);断链 → 返回全量并带 `{resync: true}`。`/ui-fields`、`/catalogs` 不变(低频)。
- 壳:`state.rs` 投影侧新增 `apply_ops(snapshot, ops) -> snapshot`(对 shell 本地快照重放 op 的 after 子树,路径写回逻辑与内核 `apply_value_at` 同构——这是壳允许的**投影演算**,不产生新语义,单测锁死与内核一致性);Snapshot 改 `Arc<Snapshot>` 写时替换,消灭每帧多份克隆。
- 缩略图批量:内核缺口① `media_thumbs {src, atMs[], width}` 一次返回多帧(磁盘缓存命中直接合并),壳 `pump_thumbs` 改批量、`push_thumbs` 去掉 O(clips×id) 全扫(建 id→clip 索引,增维护)。
- `media_browse` 200 上限截断改为带 `truncated: true` 显式标记,壳显示"已显示前 200 项,精炼搜索词可看更多"。

**交互与动效规格**:用户无感(纯性能轮);唯一可见面——**rev 脉冲点**(顶栏保存状态圆点在每次 rev 提交后 240ms 内扩散一圈,替代现在的静态文本,呼应 web 壳 rev 脉冲交互)。

**鲁棒性要求**:delta 重放任何一步失败 → 整帧全量重拉兜底(绝不带着错快照渲染);事件断流检测落地:长轮询连续 3 次失败 → 顶栏断连横幅 + 指数退避重连,恢复后自动全量对账一次(顺带修掉 `app.rs:199-202` 静默吞错)。

**验收门禁**:新增投影单测 ≥10 用例(内核真实 oplog 样本回放 golden 对拍);1k clips 工程基准:分割/移动/改属性三类操作的请求数与收敛时间进 perf 预算表;门禁全绿。

**不做**:不做 WebSocket/SSE 推送(长轮询够用,web 壳 SSE 是另一条已存在通道,桌面壳不强求同构);不做壳侧持久缓存(快照仍是易失只读副本,"壳不缓存真相"不变)。

### I3 多选与专业编辑骨架 【硬骨头 B3】

### I4 导出闭环——把最痛的等待变成可控 【硬骨头 B4】

**目标**:导出从"裸按钮一键到天黑"变成:预设对话框 → 百分比进度 + ETA → 可取消 → 完成通知 → 打开文件夹。

### I5 音频能力——听得见的半壁江山 【硬骨头 B6】

**鲁棒性要求**(自我指涉但必要):恢复流程本身有注入测试(kill -9 子进程/壳,重启断言 rev 与撤销栈由 rebuild_stacks 复原);壳态文件损坏 → 丢弃用默认;压实失败(磁盘只读)→ 跳过并日志,不阻塞启动。

**验收门禁**:kill -9 双进程混沌测试 ×3 次全部恢复;compact 后 replay 结果与压实前 golden 相等;门禁全绿。

**不做**:不做自动云备份;不做逐键录制的无限历史(OpLog 语义即历史,压实阈值是权衡点,写进 ADR)。

### I10 解耦与测试债——把桌面壳变成可长期演进的代码 【硬骨头 B8】

**目标**:偿还 0.4 节第 2/3/4/6 条:上帝实体、渲染期 mutate、超长文件、契约软点、零测试。

**改动清单**:
- **实体拆分**:DesktopApp 只留装配与泵;拆出 `SelectionStore`(I3 已立)、`ClipboardStore`、`PlaybackClock`(I1 已立)、`StatusBus`(状态栏/toast/横幅统一出口)。面板依赖子实体弱引用,**禁止再直取 DesktopApp**;
- **渲染期 mutate 消除**:`timeline.rs:481-485` 渲染中 update 兄弟实体 → 改为事件泵统一下发(播放头/选择由 DesktopApp 泵推给 TimelineView 的 setter,渲染函数纯读);
- **文件拆分**:`inspector.rs` 975 → `inspector/`(mod.rs + fields.rs + sections.rs + transition.rs + motion.rs),单文件 <400 行;`app.rs` 命令拼装(close_gap/paste 的轨道反查)抽纯函数入 `commands.rs`;
- **契约硬化**:`render_frame` 响应加显式 `framePath` 字段(内核+壳同轮,旧扫 `.png` 逻辑保留一个版本后删);缩略图 `media` 键弃用公告(内核响应只留 `file`);project_get 平铺形状宽容代码删除(schema v3 已定版一年);
- **测试从零到一**:投影纯函数 golden(state.rs)、rpc parse_envelope 表驱动、commands.rs 拼装单测、fx 模块 token 断言;交互层以"人工 checklist + 录屏"为口径(gpui 无 Playwright,诚实不硬凑 e2e);协议层已有 893 行 conformance 继续扩。

**交互与动效规格**:纯重构轮,用户不可见变化;唯一验收=所有 I1~I9 交互回归录屏重放一遍逐项打勾。

**鲁棒性要求**:重构分 5 个可独立合并的 PR 粒度,每步门禁全绿(不搞一次性大爆炸);`Box::leak`(`inspector.rs:190`)在 fields.rs 重写时替换为 arena 或 owned 方案并留注释说明生命周期。

**验收门禁**:apps/desktop `cargo test` ≥40 用例全绿;`inspector/` 最大文件 <400 行;clippy -D warnings;全交互回归录屏。

**不做**:不重写 state.rs 投影架构(增量重放 I2 已定,本轮只测试加固);不引入依赖注入框架(gpui 实体即组件,够了)。

### I11 AI 文字驱动剪辑——差异化轮 【硬骨头 B10】

**目标**:CapCut 口碑核心的本地化实现:自动字幕 → 逐句改词 → 按文本删词即剪。全部离线。

**改动清单**:
- 内核:①`asr_transcribe {src, model?}`:whisper.cpp 本地子进程(模型文件由安装器可选组件策略管理,ADR-0022 口径),输出 **wordline**(schema 已有 `schemas/wordline.schema.json`,词级时间线是现成契约);②`subtitle_track_from_wordline {wordlineId, maxCharsPerLine}`:生成文本轨 clips(文本轨语义已有);③文本驱动剪辑**不需要新命令**:选删文字 → 前端把词级时间范围合并成区间 → 现有 ClipsPatch 批量删除/闭合(B2 之后命令面齐备)——这正是"语义在内核、编排可组合"的红利;
- 壳:①字幕面板:句列表 ↔ 时间线双向联动(点句子跳播放头+选中 clip;点 clip 滚动到句);②逐句编辑:改文本即时回写 clip(Enter 提交,同检查器纪律);③"文本编辑器"视图:全文视图,删除词/句时**待删除区间在时间线上以红纹预览**,确认按钮一次提交批量 op(乐观预览纪律);④导出 SRT/ASS(ASS 主路线 ADR-0016 已定,drawtext 兜底仅记录);⑤TTS:`tts_synthesize {text, voice}` 接本地 GPT-SoVITS 服务(echosmith 已部署于本机,HTTP 可达则启用,不可达则按钮置灰显示"未检测到本地语音服务"——诚实呈现铁律),产物入媒体库并自动落 A 轨播放头处。

**交互与动效规格**:转写进行中:字幕面板顶部进度条(≥2Hz)+ 面板其余区可继续用(后台线程);句 hover 80ms 高亮 + 显示时间码;确认删除瞬间,被删区间在时间线上 240ms 折叠收拢(单次状态变化动效,合规);TTS 生成中按钮秒表态。

**鲁棒性要求**:ASR 引擎缺失/崩溃 → 明确错误卡(带安装指引链接)而非静默失败;转写结果先落 wordline 文件再生成字幕轨(两步可分别撤销);文本驱动删除在预览确认前**零提交**;模型文件校验失败 → 指纹不匹配警告(同 I9 指纹纪律)。

**验收门禁**:10min 中文口播实测:转写 ≤3min、字准抽查 ≥95%、删除-撤销-重做全链路录屏;SRT 导出与时间线逐帧对拍抽样;门禁全绿。

**不做**:不做云端 ASR/TTS;不做多说话人分离;不做 AI 抠像/补帧(GPU 预算与 GT 710 现实约束,诚实不做)。

## 7. 验收纪律(每轮通用,不赘述)

1. 门禁真实运行:fmt → clippy -D warnings → test → build,引用退出码,不口头宣称;
2. UI 交付过 ui-taste-checklist 打分留档;动效项逐条录屏(webm ≤8MB);
3. "声称已支持必须有实测,否则写回本文档待办并改归属轮次——不粉饰"(04 §4 原文沿用);
4. 每轮收尾在 CHANGELOG Unreleased 登记,版本号随下一次 ship 决定;
5. 本文档为活文档:轮次内范围变更当场改文档再改代码,文档与实现不许分叉超过一轮。
