# ADR-0023:剪映草稿导出保留(独立模块承接);本地转写(whisper 系)明确不做

日期:2026-09-30 · 状态:已采纳(册六 D-F3,动工前落库)
关联:册六迭代计划 D-F3/AC-6.3 · ADR-0008(jianying headless 只学方法不复制代码)· ADR-0017(音频分离延后评估框架)· ADR-0010(个人自用,以使用频率为准)· capability-matrix 诚实标注口径 · T6.4(随包脚本)

## 背景

册六 AC-6.3 要求四大件内置、零外部脚本调用(进程树断言零 python 子进程)。现有 `export_jianying` 编排面调 CutFlow 侧 `rs_jy_draft.py`(Python)生成剪映草稿;转写能力从未内置于 CutForge(上游 CutFlow 的 02_转写与校对阶段产物)。决策点 D-F3:这两块能力在独立化中是收编、移除还是明确不做。判定准绳 = 个人使用频率(ADR-0010):剪映草稿互通有真实用例(成片回剪映加特效是既有工作流的末端),本地转写无独立用例(素材皆短口播,字幕人工敲或上游转写件直读)。

## 决策

1. **剪映草稿导出保留,收编为随包独立脚本**:`export_jianying` 编排面与 `rs_jy_draft.py` 全部算法**归属保留**(ADR-0008 边界不动),册六起该脚本作为随包独立资产随安装器分发(T6.4),不再依赖 CutFlow 仓库在位。诚实标注:该导出面**仍依赖 Python 运行时**——不冒充"零依赖能力";能力矩阵如实写"随包脚本 + Python 运行时"。AC-6.3 的"零 python 子进程"断言范围 = **字幕/花字/卡点/重构图四大件编辑链**,不含用户显式调用的剪映草稿导出(编排面)。
2. **headless 化再评估登记**:rs_jy_draft 是否移植 Rust(剪映草稿 JSON 直接手写,参照 OTIO 手写最小子集先例)挂册七评估;现在不做——移植成本与剪映草稿格式跟进负担不匹配当前使用频率。
3. **本地转写(whisper 系)明确不做**:不做内置 ASR,不引入 whisper.cpp/模型分发。按 ADR-0017 评估框架记录:体积(模型数百 MB 起)、速度(CPU 推理分钟级/分钟素材)、维护面(模型版本跟踪)三指标全不达标,且无用例支撑;上游转写件(wordline.json)直读路径已覆盖"拿转写剪片子"的真实工作流。触发重开条件 = 真实用例出现(无网环境批量长素材需要本地转写),届时逐案 ADR。

## 取舍

- 保留剪映导出 ≠ 保留 CutFlow 依赖:收编随包后,依赖从"CutFlow 仓库在位"收敛为"Python 运行时在位",依赖面变小且如实可见;静默宣称"内置剪映导出"才是虚标。
- 明确不做转写与"尚未评估"严格区分:能力矩阵写"明确不做(触发条件见 ADR-0023)",不是"待办"。

## 被否决的替代

- **静默移除剪映导出**(为凑"零外部脚本"指标):否决——破坏既有用户路径(成片回剪映是真实工作流),且 AC-6.3 断言范围本就限定四大件编辑链;为一个不在范围内的指标砍真实能力,是指标洁癖。
- **现在引入 whisper 内置转写**:否决——无用例、体积/速度/维护三不达标(ADR-0017 框架判定),为对标清单打工违反个人自用取舍;上游转写件直读已闭环。
- **册六内移植 rs_jy_draft 为 Rust**:否决——剪映草稿格式跟随剪映版本漂移,Python 脚本层跟进成本最低;移植收益零(用户感知不变),挂册七以使用频率证据重开。

## 后果

- `export_jianying` 编排面行为零变化(脚本定位顺序:工程内 → 随包资产;CutFlow 回退保留一个版本期);PROJECT-FORMAT 第九节与 capability-matrix 口径同步(随包脚本 + Python 运行时,诚实标注)。
- T6.4 安装器资产清单增 `tools/jianying/` 随包脚本;进程监视断言(e2e_independence,册六后续任务)在四大件范围内执行,剪映导出豁免并注明。
- 转写在能力矩阵落"明确不做"条目;whisper 相关关键词在评估框架(ADR-0017)下可追溯,无"隐藏待办"。
