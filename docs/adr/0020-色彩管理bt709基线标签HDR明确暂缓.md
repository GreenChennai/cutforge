# ADR-0020:色彩管理——bt709 基线 + 全链标签,HDR 明确暂缓(诚实标注,触发条件落档)

日期:2026-09-30 · 状态:已采纳(册五 D-E3,动工前落库)
关联:册五迭代计划 T5.6/D-E3 · FLOW.md §5.6(渲染缓存与确定性)· parity 像素对拍(色彩语义确定性前提)· ADR-0010(个人自用定位)· 能力矩阵诚实标注口径 · ADR-0016(文本渲染链,标签同域复验)

## 背景

T5.6 渲染质量与控制要求:编码参数含色彩空间标签,色彩管理"bt709 基线;HDR 明确暂缓并诚实标注"(D-E3)。现状:渲染链输出 x264/yuv420p 但未显式携带 color 元数据标签(color_primaries/color_trc/colorspace);输入侧探针登记基础媒体信息,色彩空间未标注;HDR(bt2020 PQ/HLG)无任何处理路径。个人素材库现状:SDR(bt709/bt601 混杂)为主,HDR 素材为零。决策点:输出标签打到什么域、非基线输入怎么办、HDR 是做是缓。

## 决策

1. **bt709 基线 + 全链标签**:输出恒为 SDR bt709,编码显式携带完整标签(`color_primaries=bt709` / `color_trc=bt709` / `colorspace=bt709` + color_range),导出后 ffprobe 复验标签在位并纳入渲染自检;输入侧探针读取色彩三元组登记进媒体元数据(标签缺失时诚实记 unknown,不猜不补)。
2. **非 bt709 SDR 输入的归一**:探针检出 bt601 等其他 SDR 色域的输入,渲染链显式转换到 bt709 后再进既有管线(转换滤镜实现期定,以实渲对拍验证转换保真);归一不可达(探针失败/异常流)→ WARN + 按未知域直通,元数据诚实记 unknown——不静默、不猜域。
3. **HDR 明确暂缓**:不做 tone mapping、不做 HDR 输出、不做 bt2020 管线,触发前不写任何 HDR 代码。能力矩阵口径 =「明确暂缓(触发条件见下)」,与「未评估」严格区分。触发条件:**真实 HDR 用例出现**——本人素材库出现 HDR 素材且需要正确交付(HDR 直出或高质量 SDR 映射),届时按逐案 ADR 重开;输入归一层(决策 2)即重开时的现成挂载点(tone mapping 插在归一之后、管线之前)。
4. **像素对拍是本决策的验收底座**:色彩标签让"同工程同产物"的像素断言有了确定语义(无标签文件的像素比较依赖解释环境,跨机跨工具漂移);调色(T5.2)/帧证/parity 全部夹具在 bt709 域断言。

## 取舍

- bt709 是"够用且无歧义"的最小决策:个人交付面(B 站/本地播放/剪映互通)全在 SDR bt709 域;标签成本近乎零(编码参数三枚举 + 复验一行),互换歧义一次清除。
- 代价:非 bt709 输入多一道显式转换,滤镜开销计入 bench;若实测出可测量劣化,该输入类别降级为 WARN+直通并逐案留档(降级是诚实标注,不是静默放弃归一)。
- HDR 暂缓不是"永久不做":触发条件是**素材用例**而非技术好奇——无素材无用例的 HDR 管线(tone mapping 参数面/bt2020 元数据)纯为对标清单打工,违反个人自用定位(ADR-0010 谱系)与 E-R2 取舍框架。

## 被否决的替代

- **现在做 HDR**(tonemap/bt2020/PQ 管线):否决——无素材无用例,AC 无判定基准(没有真实 HDR 素材就没有"正确"的参照物);引入的复杂度全由"对标有"驱动,直接违反 E-R2"专业功能与个人自用取舍"。
- **不标色彩空间**(裸输出维持现状):否决——互换歧义:无标签文件跨播放器/剪辑工具解释漂移,交付面不可控;更关键的是像素对拍失稳——AC-5.2 调色逐帧误差阈值、帧证断言全部要求确定色彩语义,诚实纪律无从谈起。
- **输入侧 HDR 直通兼做"未来 HDR 支持"**:否决其作为支持口径——直通仅是归一失败时的诚实降级路径(决策 2);HDR 输入的现状就是"无 tone mapping 的帧面直通",能力矩阵如实标注"非色彩管理",不因直通存在而宣称兼容 HDR。

## 后果

- 渲染自检(分级自检链)增"色彩标签在位"检查项;探针 schema 增色彩三元组字段(契约走 CONTRACT-WORKFLOW 七步)。
- 调色(T5.2)所有实渲对拍在 bt709 域闭合;LUT(.cube)导入按 bt709 目标域解释并如实标注(跨色域 LUT 适配是 HDR 重开时的议题)。
- 批量渲染/多机一致性获得确定色彩语义:同工程同产物在色彩维度可判定,"颜色变了"从感受争议变为可测缺陷。
- HDR 触发重开时,以本 ADR 决策 3 的触发条件证据(素材清单 + 交付需求)开逐案 ADR,沿用输入归一挂载点,不推翻 bt709 基线(bt709 仍是 SDR 交付底座)。

## 落地证据(动工后核销)

- 输出标签 ffprobe 复验记录 + 渲染自检项。
- bt601→bt709 归一实渲对拍夹具(误差阈值内)或其降级留档(实测劣化证据)。
- 能力矩阵「HDR 明确暂缓 + 触发条件」条目;docs/PROJECT-FORMAT.md 色彩语义节(T5.5 同批)。
