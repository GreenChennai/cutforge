# ADR-0019:复合片段=内联子时间线、多机位=展开为普通片段、OTIO=手写最小 JSON 子集

日期:2026-09-30 · 状态:已采纳(册五 D-E2,动工前落库)
关联:册五迭代计划 T5.4/T5.5/D-E2/AC-5.4/AC-5.5 · E-R2(专业功能与个人自用取舍)· 总纲 C4(最小依赖纪律)· 单文件真相源纪律(FLOW.md 工程文件口径)· ADR-0010(个人自用定位)

## 背景

T5.4/T5.5 三件 IR 建模决策一次定夺(D-E2):

1. **复合片段**(嵌套时间线):IR 扩展走"引用子工程"还是"内联子时间线";
2. **多机位**:IR 建 multicam 持久实体(角度清单+同步点+活动角度)还是同步分析后展开为普通片段;
3. **OTIO 互操作**:引 otio crate 还是手写最小子集。

三者共同背景:CutForge 定位个人自用闭源(ADR-0010),工程 = 目录 + **单文件真相源** project.json + 媒体;E-R2 明文"多机位/OTIO 属锦上添花,若体验成本过高允许降级,但关键帧/调色/音频为必做";C4 最小依赖纪律要求引入依赖逐案 ADR。

## 决策

1. **复合片段 = 内联子时间线**:clip 新增 `compound: { clips: […] }`——字段结构与顶层时间线同构的内嵌 clips 数组,时间域为复合片段局部域;渲染**递归展开**:子时间线先按同一管线渲染为中间段,再作为外层片段源参与既有合成(中间段走会话 tmp + 内容寻址缓存,不入工程目录,与 ADR-0013 渲染派生物同域)。嵌套深度上限两级(AC-5.4 判定口径即两级),超深在 schema/工具层拒绝。**否决外部子工程引用**(compound 存另一工程路径,按时点解析):单文件真相源纪律——引用即引入悬空引用类(复制/移动/备份工程即断链)、原子撤销跨文件无解、渲染缓存键必须混入外部文件指纹;个人自用下"打包为复合片段"的真实需求是时间线整理与成组变换,不是跨工程复用。

2. **多机位 = 展开为普通片段**:同步分析(同源多角度素材的音频波形对齐,求各角度时移;audio_beats 同域纯计算)→ 生成**切换序列**——按切换点切开,每段是普通 clip(sourceInMs 已含同步偏移),落同一条轨。IR 不建 multicam 实体;"多机位切换"是壳侧编辑视图交互(角度并排预览 + 点击切换),落账动作就是把序列改写为普通片段的常规 Op(clip_trim/clip_update/clip_split 域),OpLog/撤销/对拍零新机制。**否决 IR 建 multicam 实体**(角度清单/同步点/活动角度三态进 IR):渲染器、schema、投影、撤销四面各养一份状态机,切换语义("活动角度"是编辑意图还是渲染事实)含混,E-R2 个人自用定位下复杂度与收益错配;展开语义下"换角度"= 一次普通片段编辑,心智一致。

3. **OTIO = 手写最小 OTIO JSON 子集**(不引 otio crate):固定覆盖 Timeline / Track(Video/Audio)/ Clip(source_range = RationalTime start/duration + rate)/ Gap / Marker / Transition(基础型)/ Stack(复合片段 ↔ Stack 映射);媒体引用为工程相对路径。导出与导入是同一份确定性映射函数(单测对拍产物,与 ADR-0016 生成纪律同型);往返语义 = **出→入→再出语义等价**(AC-5.5)。子集外的 OTIO 特性(效果栈/时间变形/深层嵌套元数据)导入时诚实跳过并 WARN 留痕,不静默丢。EDL(CMX3600)同批手写导出(纯文本,人工可读判定)。**否决引 otio crate**:C4 纪律下结论"本案不进"——所需子集面远小于 crate 全量面,crate 的 Rust 生态成熟度与维护风险不由本仓控制,换不来子集外收益。

## 取舍

- 三个决策同一条主线:**IR 保持"扁平、单文件、无持久实体"**——复合是字段不是实体,多机位是序列不是实体,OTIO 是边界格式不是内部表示。渲染器/对拍/撤销/缓存机制全部原样复用,这是三案并一次定夺的公共根据。
- 代价一(复合):递归渲染要守住深度上限与缓存键设计(子时间线渲染键 = 子时间线内容指纹,天然内容寻址,ADR-0013 派生物口径);进出复合编辑视图是壳侧会话态,IR 无"当前编辑根"概念。
- 代价二(多机位):展开落账后,"整体多机位"语义(如全序列统一后移)需逐段改——个人自用可接受,壳 toast 明示非单笔(与 A4-L7 批量同口径)。
- 代价三(OTIO):子集是"够用的交换协议"而非完整标准,对外口径就是"子集往返";`docs/PROJECT-FORMAT.md`(T5.5)明文列子集范围与逐字段映射表——诚实标注纪律,不冒充全量兼容。

## 被否决的替代

- **外部子工程引用**(复合片段):否决——真相源分裂,复制/备份/缓存/原子性四面破(理由见决策 1);若未来出现真实跨工程复用需求,按逐案 ADR 以"导入时内联拷贝"重开,引用形态仍不进。
- **IR multicam 实体**(多机位):否决——复杂度与个人自用错配(理由见决策 2);真实多机位节目级需求出现时按逐案 ADR 重开,且优先仍考虑"同步分析+序列生成"形态。
- **引 otio crate**(OTIO):否决——C4 最小依赖纪律逐案裁决"不进"(理由见决策 3);crate 演进成熟可再评估,评估面 = 子集覆盖率/维护活跃/无传递依赖。
- **OTIO 导入即展开内部 IR、导出再重组**(不做映射函数对拍):否决"静默丢"形态——子集外字段必须 WARN 留痕,往返等价才可判定;映射函数单源是往返语义的成立前提。

## 后果

- schema 扩展(compound)与 schemaVersion 升级随关键帧(ADR-0018 同批 3.0.0)走 CONTRACT-WORKFLOW 七步;迁移器对无 compound 的存量工程零改写。
- 两级嵌套实渲夹具(时长/内容逐帧断言)进 parity(AC-5.4);多机位同步分析是纯计算,产物为切换序列生成建议,不落盘不产 Op(应用时才产 Op)。
- OTIO/EDL 读写器为纯函数面:单测夹具对拍 + 往返脚本进 e2e;EDL 外部工具解析人工验证一次(AC-5.5)。
- docs/PROJECT-FORMAT.md(T5.5 公开)记载 compound 字段语义、多机位展开口径、OTIO 子集范围三节。

## 落地证据(动工后核销)

- compound schema/迁移器/递归渲染两级夹具(AC-5.4);进出复合编辑视图无损 e2e。
- 同步分析→切换序列 e2e(两角度同源素材,同步偏移可断言)。
- OTIO 往返脚本(出→入→再出逐键等价)+ EDL 外部解析人工记录(AC-5.5)。
- docs/PROJECT-FORMAT.md 三节落地;otio crate 否决案的再评估面留档本 ADR。
