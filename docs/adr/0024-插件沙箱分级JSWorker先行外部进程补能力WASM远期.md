# ADR-0024:插件沙箱分级——JS Worker 沙箱先行 + 外部进程插件双形态,WASM 远期

日期:2026-09-30 · 状态:已采纳(册七 D-G1,动工前落库)
关联:册七迭代计划 D-G1/T7.2 · ADR-0009(HTTP 层纯 std 手工加固,不加运行时的同一依赖纪律)· ADR-0010(个人自用,以使用频率为准)· G-R1(插件生态=0,验收以"自己写 3 个插件"为准)· cutforge-script 沙箱(六类逃逸零到达,既有权限模型基础)

## 背景

册七 T7.2 要给 CutForge 一等公民插件系统,核心技术选型是插件代码在**哪里执行**:
浏览器侧 Worker 沙箱、WASM 沙箱、还是宿主外部进程。判定准绳(ADR-0010 框架):
真实用例只有"自己写 3 个插件"量级(G-R1),因此选型看**边际成本/收益**,不看生态对标;
同时壳是浏览器环境(ADR-0011 无构建 ESM 壳),插件若要在编辑器 UI 内贡献命令/面板/
右键菜单,代码必须能与壳同域运行。本决策只裁技术路线与分级次序,权限模型(manifest
声明 + 首次启用确认)与生命周期在 T7.2 实现时细化,不在本 ADR 展开着落。

## 决策

1. **JS Worker 沙箱先行(浏览器内形态)**:插件代码跑在 Web Worker(独立全局、无
   DOM 全权、`postMessage` 单通道通信),崩溃隔离是浏览器天然给的(Worker 崩掉不伤
   壳主线程);API 面给**受限子集**——经消息协议访问 Editor API(`fetch` 内部转发到
   `/api/v1`,鉴权 token 不下发插件代码),贡献点(命令/右键菜单/面板/导入导出处理器)
   以声明式清单 + 消息回调暴露。适合全部 UI 贡献点场景,零新增运行时依赖。
2. **外部进程插件并行保留(CLI 协议形态,能力最大)**:插件以独立可执行/脚本形态
   经 stdio JSON 协议与 CutForge 通信(与 MCP 通道同风格),能做 Worker 做不了的
   事——执行本地命令、读工程外文件、调用 ffmpeg 等重型依赖。manifest 按权限声明
   (网络/文件系统/执行进程),首次启用确认;此形态天然进程隔离,浏览器外场景
   (CI/批处理/CLI)唯一可选。
3. **两形态共享同一套 manifest 权限模型与写通道纪律**:插件的一切工程写操作必须走
   Op 通道(纳入 OpLog,actor=plugin),Worker 形态经受限 API 面、外部进程形态经
   协议面,两态汇入同一 `dispatch` 单表——不建第二套业务逻辑。
4. **WASM 远期,触发条件落档**:仅在同时满足以下条件时重开评估——(a)出现真实
   插件需要在**无浏览器环境**下做 CPU 密集计算且外部进程形态的启动/通信开销实测
   不可接受;(b)需要跨语言插件生态(非 TS/JS 作者)的真实需求出现。触发前不做
   任何 WASM 运行时/工具链投入。

## 取舍

- Worker 沙箱 ≠ 安全边界:它防的是**崩溃与误用**(隔离、无 DOM 全权),不防恶意
  插件——恶意面由 manifest 确认 + Op 通道审计兜底(写全留痕可撤销)。个人自用场景
  威胁模型里没有对抗性第三方,为对抗性安全引入 WASM 线性内存/能力令牌是错配。
- 双形态 ≠ 两套插件系统:贡献点、权限清单、OpLog 归因三面共用,形态只差"代码跑在
  哪";避免为形态分裂出两份插件协议。

## 被否决的替代

- **仅外部进程插件**:否决——浏览器内场景(UI 贡献点:命令面板/右键菜单/自定义面板)
  每个手势都要跨进程往返,延迟与实现复杂度都不划算;且壳无法直接加载展示外部进程
  插件的 UI 面,面板类贡献点基本不可做。
- **WASM 先行**:否决——生态为零(G-R1),WASM 工具链(wasm-bindgen 一类)与
  宿主 API 绑定层的建设成本远超"自己写 3 个插件"的收益;把 ADR-0009 的依赖纪律
  (运行时只增有据)用在零需求处即是错配。触发条件见决策 4,落档可追溯。
- **VM 隔离的脚本解释器内嵌(自写解释器/嵌 QuickJS 一类)**:否决——浏览器已有
  Worker 这一免费沙箱,内嵌解释器属于重复建设;CLI 场景已有外部进程形态覆盖。

## 后果

- T7.2 插件宿主按双形态实现:Worker 宿主(壳侧加载)+ 外部进程宿主(CLI 侧);
  示例插件验收(AC-7.2)两形态各至少覆盖一类贡献点。
- 受限 API 面以 `/api/v1`(ADR-0025)为唯一通道,Worker 内不直发裸 token——
  token 代理由宿主持有。
- WASM 相关关键词在能力矩阵落"远期(触发条件见 ADR-0024)",不是"待办";
  册七不做任何 WASM 代码与依赖。
